## 2. Delegated question answered directly: does tsc still parse excluded files?

**Yes, and that is exactly why the Benefit line fails.** Reasoning from the repo's own config, no execution needed:

1. `exclude` is a *root-selection* filter. It removes candidates produced by `include`; it does not touch module resolution. `tsconfig.json:23` still maps `@/*` → `./src/*`, so `@/generated/prisma/enums` still resolves to `src/generated/prisma/enums.ts`, and any file a program root imports is added to the program. (RV-D T3/T5 reproduces this correctly.)
2. The generated directory is **import-reachable**, not ambient: 22 of 24 files are in the transitive closure of the 6 `@/generated/prisma/client` sites and the 42 `…/enums` sites (T3). Those 22 stay. Only `browser.ts` + `prismaNamespaceBrowser.ts` (444 lines) leave — they are unreachable because no hand-written file imports the browser entry.
3. `@ts-nocheck` (24/24, T2) suppresses **semantic diagnostics inside each file**; it does not suppress parsing, does not remove the file from the program graph, and does not stop its exported types from being used by importers. So the residual cost of the 29,278 lines is *parse + bind + declaration-merging + program construction* — which is real but small relative to checking, and **unchanged by `exclude`**.
4. `skipLibCheck: true` contributes **nothing** here (T4): all 24 files are `.ts`, not `.d.ts`.
5. One genuine benefit the review did not name either: `exclude` is the only defence that keeps a *future* unreachable generated file (browser entry, or a leftover file in a directory generate did not wipe because `client.ts` was missing) out of the root set. That, plus root-set/IDE noise, is the honest justification for Day 2's line — not line count.

**Experiment the plan author must run** (both are safe if the build-info is redirected; `--listFilesOnly` exits before checking):

```

npx tsc --noEmit --listFilesOnly | grep -c "src/generated"          # expect 24
#   …add "src/generated/**" to tsconfig exclude, re-run…            # expect 22

cp tsconfig.json /tmp/tsconfig.keep

```
Expected result, per T3: **a delta of order 1.5 % of files, i.e. within noise.** If the plan wants a measurable Day-2 win it should claim the 2,932-line (9.9 %) auto-shrink from deleting the two models (T8) instead, and report `tsc` time before/after — not the exclude entry.

## What this phase would have gotten wrong

1. **G3 is the new G2.** The phase's whole premise is "delete the gate that cannot fail", and it lands a
   replacement that also cannot fail: `next build` throws `E625` at
   `node_modules/next/dist/export/index.js:375-385` the moment the demo manifest registers a server action, so
   the step after `build:demo` can only ever read 0. Whoever wires `ci.yml` will spend a debugging session on a
   green step that was never going to fire. The assertion that *does* earn its place is G5's server-side
   `!==17`, which nothing else enforces — say that in the row.
2. **The CI ordering rule is built on a false premise.** `next build` runs `tsc` over the *entire* `tsconfig`
   program, `.next*/types` globs included (`02-typescript.md:39-40`). Positioning `typecheck` after
   `build:server` does not control which flavour is checked, and **the 63 figure is unreachable on CI** —
   a fresh clone has only `.next/types`, so the cap is 21, and the remaining 42 live in dev directories that
   no production build rewrites. The remedy is `rm -rf .next/types .next/dev .next-demo-dev` before
   `build:server`, not a step order.
3. **Phase 1b is handed a command that is red on a correct tree.** Measured: the regenerated init is **367**
   lines against `0_init`'s **175**, `diff` exits **1**, and the file's own contract says 1 is never a pass.
   Independently of the ruling, this cannot ship. Phase 1b gets **no drift gate**; `prisma validate` is the only
   schema check. `--shadow-database-url` is not a Prisma 7.9.1 flag, so there is no cheaper way back.
4. **G11 cannot run as a CI step and forbids the docs from explaining the refactor.** Its pass state is
   exit 1 (grep with no matches), which reds a `run:` step, and its patterns ban the very words a
   "what changed and why" section must use. Needs `!`-negation plus an allowlist.
5. **G7 is credited with policing R-01 and cannot.** Usage→definition checks stay green when a `@media print`
   / `:global` block is orphaned from the component that needs it — the exact D-3 hazard. If a later reader
   treats "G7 landed" as reason to un-defer D-3, R-01 ships broken with every gate green.
6. **G12's second clause is a word, not a check.** `grep -n "pull_request" ci.yml` is satisfied by a comment.
   Assert the four legs (`format:check`, `lint`, `typecheck`, `test`) instead.
7. **Minor but load-bearing traps:** the G3 one-liner is published twice, escaped in the table and unescaped in
